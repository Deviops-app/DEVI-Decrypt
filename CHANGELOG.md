# Changelog

## 1.0.3 - 2026-10-07

Windows release published on <https://deviops.app/tools/devi-decrypt/>. This repository holds the community scaffolding and brand assets for the open-source home; application source under `src/` follows as it is published.

- Offline decryption of Apple and iCloud OpenPGP provider returns on Windows x64.
- Read-only handling of the encrypted source; PDF verification records without keys, passphrases, or decrypted contents.
- Return workspace for a whole Apple return and its key.
- Built-in self-test against an embedded synthetic package.
- Optional update check, off by default.

## Repository

- Added Apache-2.0 license, NOTICE, contributing guides, security policy, and issue templates aligned with DEVI Validate.
