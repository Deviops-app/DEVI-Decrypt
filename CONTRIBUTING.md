# Contributing to DEVI Decrypt

Thank you for your interest in DEVI Decrypt. This repository holds the DEVI community files and brand assets for Decrypt, and is the home for the application source as it is published.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting bugs and asking for features

- **Bugs:** open an issue with the bug report form. Include the DEVI Decrypt version (About window), the operating system, the steps to reproduce, and relevant lines from `%LocalAppData%\DEVI\Decrypt\logs` when present.
- **Features:** open an issue with the feature request form.
- **Security issues:** do not open a public issue. Follow [SECURITY.md](SECURITY.md).

Never attach real provider returns, keys, passphrases, case material, or personal data to an issue or pull request.

## Pull requests

1. One logical change per pull request.
2. Fill in the pull request template.
3. Every behavior change adds a line to `CHANGELOG.md` under an "Unreleased" heading.
4. A DEVI maintainer reviews and merges every change.

The repository never contains credentials, signing keys, private keys from cases, internal infrastructure details, personal information, or case data.
